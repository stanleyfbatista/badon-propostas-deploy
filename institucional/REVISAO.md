## Arquivos e execução local

O diretório institucional está fora de public. O deploy atual do cPanel não copia este diretório, preservando o site em manutenção, o Forms, o CRM e suas configurações.

Arquivos principais:

- index.html
- assets/css/style.css
- assets/js/main.js
- servicos/trafego-pago.html
- servicos/sites.html
- servicos/google-meu-negocio.html
- servicos/identidade-visual.html

Para revisar no Mac, abra Iniciar-previa.command e depois o endereço mostrado no Terminal. Ou abra o Terminal dentro de institucional e execute:

```sh
php -S 127.0.0.1:4180
```

Acesse http://127.0.0.1:4180/ no navegador. Encerre o servidor com Control+C.

No VS Code, use Command+Shift+P, procure “Open Integrated Browser” e abra esse mesmo endereço. O servidor precisa permanecer em execução. Se não estiver ativo, execute Iniciar-previa.command primeiro.

Para validar os arquivos:

```sh
node --check assets/js/main.js
python3 tools/validate.py
```

tools/make_placeholders.py serve somente para gerar os placeholders durante o desenvolvimento e precisa de Pillow. A hospedagem não precisa desse script.
